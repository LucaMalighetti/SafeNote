SafeNote iOS - Istruzioni
-----------------------

Per utilizzare questo codice:
1. Apri un Mac con Xcode installato.
2. Crea un nuovo progetto "SwiftUI App" chiamato SafeNote.
3. Trascina questi file (.swift) dentro il progetto Xcode, sostituendo quelli esistenti se necessario.
4. Assicurati di aggiungere il permesso "Privacy - Camera Usage Description" nel file Info.plist.
5. Collega il tuo iPhone e premi Run.
